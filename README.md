# MoniVue

MoniVue is a personal finance and budget management application designed to help users track spending, manage bills, and monitor credit card debt.

The application includes a mobile and web interface with user authentication and persistent financial data.

## Features

- Track income and expenses
- Manage recurring bills
- Monitor credit card debt
- Organize financial transactions
- User authentication
- Persistent user data
- Responsive mobile and web interfaces
- Available on the Apple App Store

## Tech Stack

- React Native
- React
- TypeScript
- Node.js
- Express.js
- Supabase Auth
- PostgreSQL
- REST APIs
- Expo
